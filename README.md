Для запуска движка вам понадобятся **Python 3.12+** и следующие библиотеки:

* **GLFW** — для создания окон и обработки нажатий клавиш/мыши.
* **PyOpenGL** — для работы с низкоуровневой графикой.
* **Pillow (PIL)** — для загрузки и распаковки пикселей изображений.

### 1. Клонирование репозитория и переход в папку:
```bash
git clone https://github.com/barni22831/Engine/
cd Engine
```

### 2. Установка библиотек:
```bash
pip install glfw PyOpenGL pillow
```
