
Подсистема вывода графики (Класс render_lib)


window(width, height, name, standardBgColour)

• width — ширина создаваемого игрового окна в пикселях.
• height — высота создаваемого игрового окна в пикселях.
• name — текстовое название (заголовок) окна, которое пишется сверху.
• standardBgColour — кортеж из 4 чисел (RGBA) для цвета заливки заднего фона.

render_frame(curent_map)

• curent_map — текстовое имя локации, объекты которой нужно отрисовать в текущем кадре.

Подсистема текстур и цвета (Класс grafic_lib)


load_sprite(way, name)

• way — относительный путь к файлу изображения (например, "sprites/chel.png").
• name — уникальное текстовое имя, по которому движок будет находить эту картинку в базе данных.

set_colour(id, red, green, blue)

• id — уникальный номер физического объекта на карте, которому меняем цвет.
• red — количество красного цвета от 0 до 255.
• green — количество зеленого цвета от 0 до 255.
• blue — количество синего цвета от 0 до 255.

Подсистема шаблонов и баз данных (Класс file_lib)


map(name, size)

• name — уникальное текстовое имя для новой локации (карты).
• size — кортеж из двух чисел (X, Y) для размеров этой карты.

object(name, size, scale, interactable, resistance, sprite)

• name — текстовое имя-шаблон для создания объектов (например, "Зеленый Куб").
• size — кортеж из двух чисел (X, Y) для базовой ширины и высоты объекта.
• scale — базовый масштаб объекта (число, на которое умножаются размеры).
• interactable — флаг интерактивности (0 или 1), будет ли объект реагировать на действия.
• resistance — коэффициент сопротивления (трения) объекта, влияющий на остановку сил.
• sprite — путь к картинке, если объекту нужен графический спрайт вместо цвета.

trigger(name, size, function, args)

• name — уникальное текстовое имя создаваемого триггера.
• size — кортеж из двух чисел (X, Y) для размеров зоны активации триггера.
• function — название функции из кода игры, которая сработает, когда игрок зайдет в триггер.
• args — кортеж с аргументами, которые нужно передать в эту активируемую функцию.

nearObj(id, R)

• id — номер объекта на карте, вокруг которого мы ищем соседей.
• R — радиус (дистанция в пикселях) вокруг объекта для поиска других тел.

Подсистема физики и мира (Класс physick_lib)


place(map, obj_name, pos, scale)

• map — текстовое имя локации (карты), на которую мы ставим объект.
• obj_name — имя шаблона из file_lib.object, который мы клонируем на карту.
• pos — список из двух координат [X, Y] для точки спавна левого верхнего угла объекта.
• scale — индивидуальный масштаб конкретно для этого экземпляра объекта на карте (по умолчанию 1).

collide(id_num, id1)

• id_num — номер объекта, для которого мы прямо сейчас проверяем столкновения.
• id1 — словарь объектов-соседей для проверки (если равен None, движок автоматически вызовет nearObj).

physick(id, phis)

• id — номер объекта на карте, для которого нужно применить гравитацию, скорости и коллизии.
• phis — кортеж (гравитация, коллизия), где 1 означает включено, а 0 — выключено.

setVector(id, vector, value)

• id — номер объекта, которому мы хотим придать или изменить скорость.
• vector — текстовое имя оси движения (строка "x" или "y").
• value — числовое значение скорости, которое мы устанавливаем для этой оси.

setPos(id, posx, posy)

• id — номер объекта, который нужно мгновенно переместить (телепортировать).
• posx — новая точная координата X на экране.
• posy — новая точная координата Y на экране.

️ Подсистема обработки ввода (Класс input_lib)


bind_button(button, function, args, pressType)

• button — текстовое название клавиши (например, "w", "d" или "mouse_left").
• function — функция, которая должна сработать при действии с этой кнопкой.
• args — кортеж аргументов, которые полетят внутрь вызываемой функции.
• pressType — режим срабатывания кнопки ("short" — один раз при нажатии, "long" — зажатие клавиши).
